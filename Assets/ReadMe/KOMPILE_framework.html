[Framework] Core Guidelines

Unity 6000.x Development Standard | Target: 나으리(Na-euri)

Rule 1 Component

게임 오브젝트에 부속되어 기능을 수행하는 최소 단위.

  • 명칭: ...Component, I...
  • MonoBehaviour 상속 필수

Rule 2 IngameObject

Component들의 조합으로 구현된 게임 내 논리적 실체.

  • 독립적인 개체 (Player, Enemy)
  • Manager에 의해 생명주기 관리

Rule 3 System

Manager가 제어할 에셋이나 데이터를 공급/관리하는 클래스.

  • 명칭: ...System
  • Asset, Sound, Save 데이터 핸들링

Rule 4 Manager

여러 개의 IngameObject를 제어하고 게임 흐름을 조율.

  • 명칭: ...Manager
  • 상태 전이 및 핵심 로직 트리거

Rule 5 Utility

상태 없이 오직 계산(Input-Output)만 수행하는 순수 함수군.

  • 명칭: ...Util
  • Burst Compile 최적화 대상

Rule 6 Data (New)

정보의 상태, 구조, 가공 형태 및 자료형 정의.

  • Static: Table, Entity
  • Runtime: Context, Model
  • Define: Type, Info

📂 Directory Structure Reference

Assets/Scripts/
├── Managers/ // Global/Field/Battle Managers
├── Systems/ // Asset/Map/Save Systems
├── Components/ // Player/Enemy Components
├── Utilities/ // Math/Geometry/Navi Utils
└── Datas/ // All Information & Definitions
    ├── Tables/ // Read-only (ScriptableObject, JSON)
    ├── Contexts/ // Processed Runtime Data
    └── Definitions/ // Enums, Consts, Structs

🛠️ Data Classification Summary

분류 상세 설명 접미사 예시
Static Data 변하지 않는 원본 저장 데이터 ...Table, ...Entity, ...Data
Runtime Data 가공된 일시적 상태/상황 정보 ...Context, ...Model, ...Runtime
Definition Data 공용 자료형 및 열거형 정의 ...Type, ...Info, ...Define
