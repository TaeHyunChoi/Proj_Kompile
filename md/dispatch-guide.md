# Dispatch 활용 가이드 — KOMPILE

## Dispatch란?
Claude 데스크탑(Cowork)에 모바일 등 외부에서 작업을 "보내는" 기능.
데스크탑의 파일 접근 + Cowork 실행 능력을 모바일의 간편한 입력과 조합한다.

```
[모바일 Claude 앱]  →  Dispatch 전송  →  [데스크탑 Cowork 실행]
     간편한 지시                              파일 생성/수정/조회
```

---

## 효과적인 Dispatch 요청 패턴

### ✅ Dispatch에 적합한 작업
| 요청 예시 | 처리 결과 |
|-----------|-----------|
| `"Enemy 기본 클래스 만들어줘"` | Scripts/Enemy/Enemy.cs 생성 |
| `"PlayerController에 대시 기능 추가해줘"` | 기존 파일에 메서드 추가 |
| `"현재 Scripts 폴더 구조 보여줘"` | 폴더 트리 반환 |
| `"오늘 작업한 파일 목록 알려줘"` | 최근 수정 파일 조회 |
| `"TODO 주석 전체 찾아줘"` | 프로젝트 내 TODO 목록 반환 |

### ⚠️ Dispatch보다 직접 대화가 나은 작업
- 설계 논의, 아키텍처 결정
- 여러 번 피드백이 필요한 복잡한 구현
- 코드 리뷰 및 상세 설명 요청

---

## 요청을 잘 쓰는 법

### 기본 형식
```
[동사] + [대상] + (선택: 위치/조건)
```

### 예시 비교
| 모호한 요청 ❌ | 명확한 요청 ✅ |
|----------------|----------------|
| "AI 만들어줘" | "순찰-추적-공격 3단계 상태머신 EnemyAI 클래스 만들어줘" |
| "코드 고쳐줘" | "PlayerController.cs의 점프 로직에서 이중 점프 버그 수정해줘" |
| "정리해줘" | "Scripts/Utils/ 폴더의 파일 목록과 각 파일 역할 요약해줘" |

### 컨텍스트 추가 팁
- 관련 파일명 언급: `"PlayerController.cs에서..."`
- 기준 명시: `"Enemy 클래스를 상속받아서..."`
- 완료 기준 명시: `"...하고 완료되면 파일 경로 알려줘"`

## 권장 모바일 사용 시나리오

### 이동 중 아이디어가 떠올랐을 때
```
"나중에 구현할 아이디어 메모: 
 플레이어가 벽에 닿으면 슬라이딩 애니메이션 재생
 → docs/ideas.md에 추가해줘"
```

### 자기 전 다음 날 작업 준비
```
"내일 작업 시작용으로 Scripts/Player/ 폴더 현황이랑
 TODO 주석 목록 정리해서 docs/next-session.md로 만들어줘"
```

### 빠른 코드 생성
```
"ScriptableObject 기반 ItemData 클래스
 (id, name, icon, description 필드 포함)
 Scripts/Data/ItemData.cs로 만들어줘"
```

## Project Instructions와의 연동

Dispatch 요청에 스탠다드를 매번 쓸 필요 없는 이유:
Project Instructions의 **"Dispatch 전용 지침"** 섹션이 자동으로 적용됨.

→ 짧고 명확한 지시만으로 올바른 코드가 나온다.
